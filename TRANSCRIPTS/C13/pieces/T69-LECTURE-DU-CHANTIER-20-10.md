## Ce que j'ai (re)appris sur le fond, à tenir dans tout mandat
11. **Pas de codage sans vue d'ensemble** (plan, 01/08) : le chapitre déclare ses notions → la Concordance → le profil longitudinal → le conseil → M20. Un champ ajouté est un champ dont quelqu'un dépendra ; l'aval lit son absence comme une information. Le déroulé est **le point d'entrée de cette chaîne** (CADRAGE-INTEGRATION) : tout ce que l'heure produit sur un élève doit être « apparent dans le code », dans la structure nommée (cadrage 1 §11b.5, cadrage 3 §3).
