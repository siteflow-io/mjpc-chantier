Test — envoyer le tableau sur l'écran 2

Une page de rien : elle vérifie, chez toi, avec ton vidéoprojecteur, que Chrome et Windows font ce qu'on attend. Rien n'est enregistré nulle part.
1. Connecte le vidéoprojecteur : Win + K, choisis-le. (Windows a mémorisé « Étendre » : l'écran doit s'étendre tout seul. S'il duplique, Win + P → Étendre.)
2. — Chrome te demandera une fois : « … souhaite gérer les fenêtres sur tous vos écrans » → Autoriser.
3. — la fenêtre doit apparaître sur le vidéoprojecteur, en plein écran, sans que tu la glisses ni la redimensionnes. Ici, tu gardes cette page.
4. Éteins ou déconnecte le vidéoprojecteur : la fenêtre doit se fermer d'elle-même et le message le dire. connecté
