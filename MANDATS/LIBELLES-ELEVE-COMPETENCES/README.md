# Les libellés élève des compétences — proposition (10/10/2026, tour 628)

Demande de Paul (10/10, 08:54) : « les compétences ne doivent pas être mentionnées telles quelles. il faut utiliser la reformulation élève (normalement elle est sur mjpc il me semble) ».

Mesuré le 10/10 à 08:55, en lecture seule : au hub, `/taxonomie/competences` ne porte, pour chacune des 28 compétences, qu'un code et un libellé (le libellé officiel) ; aucun libellé élève, ni au hub (`/taxonomie`, `/site`), ni dans le code de la production, ni au sas. Le libellé élève existe pour les **notions** (`libelleEleve`, dans l'éditeur de taxonomie du panneau prof de MJPC), pas pour les compétences.

Proposition : chaque compétence reçoit un libellé élève, réglé dans le même éditeur, comme pour une notion. Le libellé officiel reste pour École Directe et pour le PDF « notes et compétences » ; tout ce que voit l'élève prend le libellé élève.

Les 28 libellés ci-dessous sont **proposés par la conscience n°12, à valider ou corriger par Paul** : aucun n'est vu par un élève avant.
