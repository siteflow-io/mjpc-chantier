# L'app QCM (`evaluation-qcm.html`) — connaissance mesurée (conscience n°12, 07/10/2026)
*Mesuré sur la production 7.7.1 (533 Ko, 8 820 lignes, 43 composants, 271 fonctions ; md5 `ecae65624855a1a877708986a8e984e5`), sur une copie locale du hub en lecture seule, et en rejouant une séance (professeur + tablette d'élève sur un même faux hub). Rien n'a été écrit au hub.*

## 1. Le principe pédagogique (son propre mode d'emploi)
Évaluations sommatives en classe. **Le papier reste roi** : pour chaque question, l'élève **rédige d'abord sa réponse en entier sur sa feuille** (phase « réflexion » : énoncé seul, chrono selon le niveau) ; puis le professeur clique « Autoriser la réponse » : les choix A–D apparaissent, l'élève **pose son stylo** et touche la (les) lettre(s) (phase « réponse », chrono court) ; entre deux questions : « Attends la prochaine question ». Après la dernière : **correction immédiate en classe**, questions triées par taux d'erreur, consignes stylo vert / rouge ; puis ramassage, « Terminer la session ». Le soir : le professeur scanne et téléverse chaque copie (Résultats → l'élève). À la maison : l'élève **saisit ses réponses papier** dans l'app, ce qui débloque ses résultats détaillés.

## 2. Les scores
Score app (lettres touchées, informatif) · score papier (d'après sa saisie) · **score officiel** (École Directe) = papier + « bonus écart isolé favorable » (juste sur l'app, faux sur la copie pour 1–2 questions isolées : erreur de recopie, il garde le point) ; une question à réponses multiples partiellement juste compte faux. **Quatre niveaux** (facile, standard, approfondi, expert) : couleur, durée de réflexion (réglable : `NiveauxEditor`, au moment de la mesure F 10 s · S 15 s · A 20 s · E 30 s) et **pondération** (réglable : `PonderationEditor`, défaut 1/2/3/4).

## 3. Côté professeur (`?mode=prof`)
- **Pilotage** : « Préparation » / « Évaluations » (liste ; ✏️ Modifier — **toute modification crée une nouvelle VERSION**, les sessions passées gardent l'énoncé et le barème d'origine, résultats jamais mélangés ; 🖨️ Imprimer — la feuille papier : énoncés + cadres « Rédige ta réponse en entier ici » + lettres sans contenu ; 📋 Dupliquer ; 🗑️ ; ➕ Nouvelle évaluation — on colle le JSON d'une IA, « 🔍 Vérifier le format » ; 🤖 Prompt IA — le prompt, modifiable, rangé au hub) ; « Pilotage classe » : classe + évaluation → « 🚀 Lancer la session » → **check-in « qui est absent aujourd'hui ? »** (« ✅ Tout le monde présent ») → le poste de pilotage `SessionLive` : compteurs (connectés, ont répondu, justes, question), durées des niveaux, « ▶️ Lancer Q1 », « ✋ Autoriser la réponse », « ← Q préc. / Q suiv. → », « 🔓 Rouvrir pour tous », « 🚫 Départ d'un élève », les bulles des élèves (couleurs en direct), puis autoévaluation, « 📝 Lancer la correction », le **Bilan classe** (répartition par fourchettes vert / bleu / orange / rouge), « 🛑 Terminer la session ». Une session interrompue (onglet fermé, plantage) est détectée et reprise.
- **Données** : « 📊 Résultats » (les sessions : au hub, 4 — 07/10 classe test ; 17, 18, 19/06 Les Misérables) → **Scoresheet** (tri, score app / papier / officiel, écarts, export CSV) → **Student Report** (réponse cliquée, réponse saisie depuis la copie, bonne réponse ; le scan JPG/PNG ≤ 2 Mo) ; « 💾 Sauvegarde » (export / import JSON de toute la base QCM, suppression de toutes les évaluations ; la purge des classes se fait depuis la console MJPC).
- **Réglages** : les classes appartiennent au site MJPC (lien vers la console) ; « 💬 Ce que lisent les élèves » (éditeur des phrases des tablettes, retour au texte d'origine ; les messages qui constatent un état ne sont pas modifiables).
- En tête : « 📖 Mode d'emploi », « 📺 Ouvrir vue tableau » (`VueBoard` : la projection — chrono circulaire, « les choix n'apparaîtront qu'après la réflexion », se met à jour seule), « 📱 QR pilotage » (`VuePhone` : piloter la séance au téléphone), « 🧪 Mode test » (`AppTest` : une classe et des élèves fictifs, purge, export du test).

## 4. Côté élève (`?mode=eleve`)
« 🎓 Choisis ta classe » (la liste de toutes les classes, y compris les classes de test) → « 👋 Identifie-toi » (code à 4 chiffres + prénom + nom, vérifié par **empreinte** ; ou directement si l'élève est déjà connecté au site MJPC) → « ⏳ En attente du démarrage… » + « Comment ça marche pour cette évaluation » → les questions (réflexion / réponse / attente) → l'autoévaluation (« Combien de bonnes réponses penses-tu avoir données ? », une fourchette) → la correction (« On corrige d'abord les questions les plus ratées par la classe », un compteur qui se complète) → « 🎉 Correction terminée » ; à la maison : « 📊 Mes évaluations » → « 📝 Saisis tes réponses papier » → les résultats (score officiel, copie scannée, détail des questions, « tu as cliqué un choix différent de ce que tu avais écrit ») → le **bilan personnel** (« Tu te connais bien ! » / « Tu pensais avoir mieux fait » / « Tu te sous-estimais ! »). Réseau coupé : réponses gardées sur le poste, renvoyées au retour, bandeau jaune.
