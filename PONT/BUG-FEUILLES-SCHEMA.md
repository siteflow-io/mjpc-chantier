# BUG PRIORITAIRE (Paul, 24/08, constaté avec l'instance chapitre) — LES FEUILLES NE PORTENT PAS DE SCHÉMA
Les feuilles de l'atelier ne savent pas porter un SCHÉMA, une FRISE ou une CARTE MENTALE comme le fait
une diapo du déroulé (le moteur a le bloc {t:"schema", forme:"carte", src:"Famille : a, b"} — l'atelier
n'a aucune composante équivalente). À RÉGLER EN PRIORITÉ (mot de Paul).
Piste naturelle à instruire sur pièces : porter le rendu schéma du moteur (déjà écrit, AT_DR_B64) vers
une composante de feuille — même syntaxe src, même moteur de dessin, pour ne pas dupliquer. Vérifier :
les composantes existantes de l'atelier (ATELIER_COMPOSANTES ?), le rendu imprimable (la liasse), et
le prompt v3 fiche_seance (la composante nouvelle doit y entrer pour que les instances la produisent).
