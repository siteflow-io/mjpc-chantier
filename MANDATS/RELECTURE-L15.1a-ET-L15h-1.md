# RELECTURE DES DEUX RAPPORTS À BLANC — par la conscience n°12, sur ordre de Paul (05/10, tour 492 : « fais la relecture du rapport, je n'ai pas le temps »)
*Vaut « ok » de Paul pour L15.1b-1 et L15h-2, avec les ratures ci-dessous. Paul réécrira les commentaires dans ses mots plus tard, dans Réglages (L15.1b-1 les rend éditables) — on ne l'attend pas pour demain.*

## A. L15.1a — l'analyse des erreurs (1 407 erreurs recopiées, 92 % reconnues) : OK, avec six ratures
1. **« travailles / travaille / travaills → travail »** (Hugo, Turing : ~12 lignes) — classées « Consonne double + féminin pluriel en trop » : **hors sujet**. L'élève a écrit le verbe (« il travaille ») à la place du nom (« le travail »). → **Nouvelle catégorie « Verbe à la place du nom (le travail / il travaille) »**, famille homophones, commentaire : « Tu as écrit « {forme} » : c'est le verbe ; ici c'est le nom « {mot} » (on peut mettre « un », « le » devant). » Motif : forme = radical du nom + e / es / ent. Tant qu'elle n'existe pas : « autre ».
2. **« Beaucoups → Beaucoup », « loins → loin »** (G) — « Pluriel en trop : ici le mot est au singulier » : **faux, ces mots sont invariables**. → **Nouvelle catégorie « Mot invariable »** (liste : beaucoup, loin, encore, toujours, jamais, trop, très, assez, puis, alors, ensuite, souvent, aussi, bientôt, longtemps, ici, là, autrefois…), commentaire : « Tu as écrit « {forme} » : « {mot} » est un mot invariable, il ne prend jamais de -s. »
3. **« exhumes → exhume », « tombes → tombe » (G, un verbe avec un -s de 2e personne)** — classées « Pluriel en trop » : **le commentaire est faux pour un verbe** (« le mot est au singulier »). → Quand le mot attendu est un verbe (il est dans la table des terminaisons, ou finit par -e / -ent / -ait et la forme ajoute -s), **la catégorie « -s / -x / -t final du verbe (la personne) » prime** sur « Pluriel ». Même règle pour « -nt manquant » : si la forme est en -s (« étais → étaient »), le commentaire dit aussi la personne : « Tu as écrit « {forme} » (2e personne) ; le sujet est « ils / elles », au pluriel : « {mot} ». »
4. **« quelque → quelques » (L)** — « Lettre muette finale » : **hors sujet** : c'est un accord. → En L, un -s / -x final manquant ou en trop reçoit **le commentaire du pluriel** (« il manque la marque du pluriel »), pas « lettre muette » ; la catégorie reste « Pluriel manquant / en trop » quel que soit le type posé (le type ne change pas, seul le commentaire est choisi).
5. **« demandes → demander », « abattir → abattirent », « partir → parties »** (« autre ») : acceptable en « autre » ; mais **« demandes → demander »** doit entrer dans « Terminaison -é / -er / -ez… » (le -es est une terminaison verbale confondue avec -er) : ajouter -es / -e / -ent aux alternatives de cette catégorie.
6. **Tout le reste du tableau 4 est juste** (échantillon de 45 lignes relues, plus les 52 doubles écarts : « ammener → amenés », « etais → étaient », « goûte → goutte » — bien nommés). Les 97 « autre » sont bien des formes trop éloignées (« ures → eurent », « neuvent → neuves ») : l'honnête y est le bon. Les commentaires des 38 catégories : **gardés tels quels pour demain**, Paul les réécrira dans Réglages.

## B. La césure (150 mots) : 146 justes, 4 à corriger
- **« loy·ers » → « lo·yers »** (2 syllabes : le y vaut deux i, on coupe avant).
- **« a·ris·to·cra·ti·que » → « a·ris·to·cra·tique »** (5 : le -e final ne fait pas de syllabe — la propre règle du moteur ; « ti·que » est un bug à corriger et à banquer).
- **« pu·an·teur » → « puan·teur »** (2 : « ua » se prononce d'un coup ; même règle que « quo·ti·diennes »).
- **« d'ou·vriers » → « d'ou·vri·ers »** (3 : après consonne + r ou l, « i + voyelle » fait deux syllabes : ou-vri-er, pri-er, cri-er, ou-bli-er, san-gli-er) — **règle à ajouter** au moteur.
- Les autres 146 sont justes (lo·gement, ra·pi·dement, scin·til·lement, na·tu·rel·lement, mer·veil·leu·sement : le e caduc intérieur ne compte pas non plus — confirmé).

## C. L15h-1 — le reclassement en C (27 lignes) : OK, avec deux lignes rayées et une phrase tranchée
- **« cela → ce-là »** (Dylan n° 9) : **reste en L** (ce n'est pas qu'un signe : l'élève a écrit deux mots).
- **« même → mémé »** (Turing n° 1) : **reste en L** (c'est un autre mot).
- Les 25 autres : **reclassées en C** (corbeille d'abord, compté), comme le rapport le propose.
- **La phrase de la fiche** (523) : le L se décrit **« Orthographe du mot »**, à côté de « Accent, majuscule ou trait d'union » pour C.
