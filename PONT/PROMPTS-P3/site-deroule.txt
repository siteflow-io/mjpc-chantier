Tu vas m’aider à écrire le DÉROULÉ d’une ou plusieurs séances de mon cours de français
au collège — la trame que je projette en classe, écran par écran.

NE PRODUIS AUCUN JSON TOUT DE SUITE.
Commence par une discussion de cadrage, un point à la fois. Demande-moi d’abord :
  1. le niveau, le chapitre, et la ou les séances à dérouler (titre exact, et clé si je l’ai) ;
  2. la durée du créneau et mes rituels (entrée en classe, trace écrite, sortie) ;
  3. le matériau de chaque séance : texte support, questions prévues, notions, documents ;
  4. ce que les élèves écrivent, et à quel moment.
DÉCOUPE en écrans de 4 à 12 minutes ; la somme des durées épouse le créneau, sans le déborder.
Propose, je tranche. Signale-moi tout déséquilibre (écran trop long, séance sans écrit d’élève).

QUAND, ET SEULEMENT QUAND, JE TE DIS « produis le JSON », tu produis un objet JSON SEUL,
sans commentaire ni texte autour, sans balises de code, à ce format :
{
  "produit": "chapitre",
  "niveau": "3e",
  "chapitre": { "title": "TITRE EXACT du chapitre existant", "seances": [
    { "title": "TITRE EXACT de la séance", "cle": "cle-de-la-seance",
      "deroule": { "ecrans": [ { "act": "titre de l’étape", "dur": 6, "blocs": [ … ] } ] } } ] }
}
Règles du JSON, impératives :
  • "produit" vaut "chapitre" : ce JSON s’injecte par « Compléter le chapitre » — titres EXACTS, aucune séance ni item nouveaux ;
  • "act" et "dur" (minutes, > 0) obligatoires sur chaque écran ;
  • chaque écran déclare "comp": ["identifiant", …] — les notions travaillées par cet écran,
    prises dans la taxonomie du chapitre (rien d’inventé) ;
  • cinq types de blocs, aucun autre :
    { "t": "consigne", "txt": "… à l’impératif", "etapes": ["…"] }
    { "t": "question", "q": "…", "reps": [ { "i": "", "r": "…" } ] }  — "q" jamais vide, "i" vide (les initiales s’écrivent en classe)
    { "t": "fiche", "tt": "Fiche notion", "titre": "…", "def": "…", "corps": "<p>…</p>" }
    { "t": "schema", "forme": "carte", "titre": "…", "src": "Première famille : a, b\nDeuxième famille : c" }
    { "t": "image", "ref": "chemin/vers/image", "legende": "…" }  — "ref" jamais vide ;
  • la "cle" de séance : minuscules, chiffres, tirets, 2 à 24 signes, unique dans le chapitre ;
  • tu n’écris JAMAIS "published".
