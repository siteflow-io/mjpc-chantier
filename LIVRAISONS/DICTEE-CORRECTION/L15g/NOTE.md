## Ce que ça change pour toi
- **1–2. Les profils de barème** (`site/baremes/<id>`, préservé par la purge) : **Brevet** — verrouillé, le texte officiel DNB (G 1 · L 0,5 · mot oublié 0,5 · illisible 0,5 · mot en trop 0,5 · ponctuation et accents **au forfait 0,5 par 4, plafonné à 2** · une erreur répétée sur le même mot une seule fois · plusieurs erreurs sur le même mot : la plus grave) ; il s'ouvre en lecture (« 👁 Voir le profil »), sans « Enregistrer » ; **Préparée** — ton profil actuel (G 1 · L 0,5 · M 1 · I 1 · mot en trop 0,5 · ponctuation 0,5 l'unité · pas de répétition), modifiable ; **tes profils** — « ⧉ Dupliquer » crée une copie que tu nommes. **Un profil règle** : les coûts de G, L, M, I, mot en trop, accent / majuscule (le type C de L15h) et de la ponctuation ; la ponctuation et les accents à l'unité ou **au forfait** (points, par n erreurs, plafond) ; **la répétition** : non / par mot exact / **par famille** (ta liste, une famille par ligne : « leur/leurs ») ; la base.
- **3. Choix par dictée** (Préparation, « Barème ») ; **changer de profil puis « Enregistrer »**, ou **modifier un profil** (« ✎ Modifier le profil » → « Enregistrer le profil »), **recalcule les copies** (de cette dictée / de toutes celles qui utilisent ce profil) : **la corbeille d'abord** (`recalcul-preparation_…`, `recalcul-profil_…`), **compté**, et un message : « n copies recalculées (le barème ou la base a changé) ; l'état d'avant est dans la corbeille. » Les dictées existantes gardent leur barème (brevet → Brevet, preparee → Préparée) : **leurs notes ne bougent pas** (mêmes coûts ; seul ajout : le plafond de 2 du forfait Brevet, qu'aucune copie au hub n'approche).
- **4. L'accueil** nomme le profil sur la ligne de la dictée (« barème Ciblée »). **5.** L'aide « ? » (Préparation : le profil, « Modifier », « Dupliquer » ; Suivi : l'heure et MJPC), les infobulles.
- **6. Une seule fonction de note**, dans l'ordre validé (C12 429) : (1) les erreurs sans coût retirées (formes acceptées L11, hors trous L14) ; (2) un seul type par mot, le plus grave ; (3) les répétitions (par mot exact, ou par famille) ; (4) le forfait, avec son plafond ; (5) le reste à l'unité. Utilisée partout (correction, copie de l'élève, bilan, recalculs).
- **8. Changer la base recalcule les copies (dette 130)** : la « Note sur » de la dictée (copies ordinaires) ou de la version aménagée (copies aménagées : leur trace prend la nouvelle base) → toutes les copies concernées recalculées aussitôt (corbeille d'abord, message compté). **Le Bilan dit ce qu'il compte** : « Moyenne — n copies ordinaires : x/20 » et « k copies aménagées, à part, sur leur base : y/20 ».
- **9. Le branchement MJPC, préparé (rien n'est branché)** : **un seul point d'entrée**, `heureDeLaDictee(heure)`, pour l'heure d'une dictée — l'élève, le Suivi, l'accueil, la clôture, la déconnexion passent par lui ; **« Lancer » écrit `source: "dictee"` et `seanceId: ""`** ; le marqueur **`[BRANCHEMENT MJPC — déroulé]`** (sur le point d'entrée et sur l'écriture de l'heure) dit ce qui reste à faire (si `source === "mjpc"`, lire `seances/<seanceId>`) ; l'aide du Suivi : « L'heure peut, plus tard, suivre celle d'une séance MJPC. »

## Deux points ouverts (dits, pas comblés)
- **7. La touche du type C** (accent / majuscule / trait d'union) : **proposée avec L15h**, qui définit ce type en entier (menu, couleur, légende, feuille de l'élève, aide) — une touche seule poserait un type que la feuille et la légende ne connaissent pas encore. En L15g, les profils ont déjà son coût et le forfait le compte. *À trancher par Paul (406).*
- **La base d'un profil** : elle est rangée dans le profil et réglable dans l'éditeur, **mais c'est la « Note sur » de la dictée qui compte** pour ses copies. *À trancher par Paul : la base d'un profil doit-elle s'imposer aux dictées qui l'utilisent (leur « Note sur » change, leurs copies sont recalculées), ou être seulement la base proposée quand on choisit ce profil ?*
